## Types

```ts
interface Finding { id: string; kind: 'total'|'topN'|'trend'|'share'|'compare'|'distribution'; columns: string[]; chart: ChartSpec; score: number; facts: Record<string, number|string> }
interface ChartSpec { type: 'bar'|'line'|'doughnut'|'scatter'|'histogram'; labels: string[]; datasets: { label: string; data: number[] }[]; axis?: { x: string; y: string } }
interface Deck { source: { name: string; sheet: string; rows: number; cols: number }; lang: 'en'|'ar'; slides: Slide[] }
interface Slide { id: string; kind: 'title'|'finding'|'quality'; title: string; finding?: Finding; hidden: boolean }
```

## Rules

Pure functions, no DOM, no React. Dates bucket by the range: ≤ 60 days by day, ≤ 18 months by week or month (whichever gives 6 to 60 points), else by month or quarter. Others = the rest of the categories summed. Pearson r on rows where both numbers are present.

## Titles

Templates per kind and language in `titles.ts`; the Arabic ones written as real sentences, not word-for-word translations (e.g. 'المبيعات حسب المنطقة: الرياض في الصدارة بنسبة 42 %').
