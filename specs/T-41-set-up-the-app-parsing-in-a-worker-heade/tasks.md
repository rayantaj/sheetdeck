# Set up the app: parsing in a worker, header and type detection, the landing and sheet picker, the privacy policy, Pages: tasks

Built as T-41.

- [x] Scaffold: Vite + React 18 + TypeScript, ESLint (Vite's flat config), Vitest, Playwright (@playwright/test, chromium only). package.json scripts: dev, build (tsc -b && vite build), lint, test (vitest run), test:e2e (playwright test, against `vite preview` of dist/ on port 4173), preview. vite.config.ts with base '/sheetdeck/'. Keep src/styles/tokens.css and base.css as they are and import them first in src/main.tsx.
- [x] index.html: lang='en', <title>sheetdeck</title>, a meta description, the viewport, and the Content Security Policy meta exactly as docs/tech.md states (default-src 'self'; connect-src 'none'; img-src 'self' data: blob:; font-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self'; form-action 'none'; base-uri 'none'). Fonts through @fontsource/syne (700), @fontsource/onest (400, 500), @fontsource/jetbrains-mono (500), @fontsource/ibm-plex-sans-arabic (400, 500), imported in main.tsx so Vite bundles them.
- [x] src/workers/parse.worker.ts: a Web Worker that receives a File, parses .xlsx/.xls with the xlsx package and .csv with papaparse (delimiter auto-detected), and posts back Sheet[] = { name, rows: Cell[][] } where a cell is string | number | boolean | Date | null. src/engine/parse.ts wraps the worker in a promise: parseFile(file) → Sheet[].
- [x] src/engine/detect.ts: detectHeaderRow(rows) and applyHeader(sheet, headerRow) → Table { columns: { name }[], rows: Row[] } as docs/architecture.md describes; detectTypes(table) → Column[] with type and stats (count, empty, distinct, min, max, sum, mean for numbers; min and max for dates). Tests with three fixture sheets in test/fixtures/ (a sales CSV with a date, a category and two numbers; an Excel export with a title row above the header; an Arabic-headed sheet).
- [x] src/App.tsx + src/ui/DropZone.tsx + src/ui/SheetPicker.tsx: the landing (the headline, one sentence, the drop zone as a Terrazzo card with the hard offset, a 'Try a sample' link that loads public/sample-sales.csv from the page's own files, the 'Nothing leaves this device' line) and the sheet picker (sheet tabs, a five-row preview table under a 2px ink rule, the detected header row in accent-soft and changeable by clicking a row, a Continue button). Continue shows, for now, a summary card: N rows, M columns, each column's name and detected type. src/i18n.ts with the strings in en and ar; the interface language toggles with a header button and is kept in localStorage.
- [x] A Playwright test (e2e/privacy.spec.ts): open dist/ through vite preview, drop test/fixtures/sales.csv, reach the summary, and assert every network request's URL starts with the page's own origin and path (no other host, no data: exfil), and that the CSP meta is present with connect-src 'none'.
- [x] .github/workflows/pages.yml: on push to main: checkout, setup-node 22 with npm cache, npm ci, npm run build, configure-pages, upload-pages-artifact (dist), deploy-pages; permissions contents read, pages write, id-token write; concurrency 'pages'. README.md: one paragraph, the privacy rule, the link.
